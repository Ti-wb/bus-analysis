# Bus coming soon｜公車路網需求分析

**繁體中文** · [English](README.en.md)

以開放資料支援公車路網改善的地圖工具。讓市府、客運業者、駕駛與民眾理解服務現況，找出值得調查的問題，並試改路線、比較影響。

**探索現況 → 排出改善優先順序 → 編輯路線方案 → 比較影響 → 共同討論**

[開啟網站](https://bus.tw.pe/)

## 目前可以做什麼

| 功能 | 使用方式 |
| --- | --- |
| 探索地圖 | 切換站點覆蓋、公車計畫班次、需求落差與村里年齡圖層；班次與需求分析可選擇平日／週末及時段。 |
| 查看站點與周邊 | 搜尋公車、捷運與 YouBike 站點，查看周邊人口、年齡與重要設施；也可從公車站聚焦查看服務路線。 |
| 排定改善優先順序 | 依路線、站位／路段、彈性運輸（DRTS）候選區塊或端點站篩選排序，切換清單與地圖、查看評分與詳情，再帶入路線編輯。 |
| 試改路線 | 新增、編輯或刪除路線，調整站序、路徑與時段班次；新增時可參考周邊既有服務。地圖隨選站、調整路徑與預覽步驟收斂顯示內容。 |
| 比較方案影響 | 分開查看服務增減與方案班次，並比較可達人口、周邊設施與草圖單程估時。預覽後可套用、回顧與復原。 |
| 分享與討論 | 分享探索地圖或改善清單的視圖條件，匯出篩選後的清單 CSV，並查閱資料來源與判讀限制。 |

## 從哪裡開始

第一次開啟網站可跟隨快速導覽，之後也能從「資料與方法」重新開啟。建議先搜尋熟悉的站點，了解周邊服務，再從改善清單挑選候選路線，進入路線工具試改並比較影響。

網站介面與操作文件目前以繁體中文提供。

## 使用前需要知道

- **各功能範圍不同**：班次與部分人口／年齡分析已涵蓋臺北、新北與基隆；站點覆蓋、需求落差、改善清單與路線方案仍以臺北市資料為主。
- **計畫與推估不等於實測**：班次來自計畫班表，覆蓋使用直線距離，人口與年齡包含範圍估算；不代表即時到站、實際步行可達性或乘客量。
- **改善清單含 Mock Data**：部分需求、評分與建議使用示意資料，適合提出與核對假設，不能直接作為減班或撤線依據。
- **路線方案保存在目前瀏覽器**：已套用方案可保留與復原，未套用草稿重載後會遺失；分享連結不包含本機方案，方案也不會改動實際營運路線。
- **仍有待補功能**：高齡／學生的方案影響，以及完整營運與駕駛休息可行性評估尚未提供；草圖路徑不代表已驗證可行駛。
