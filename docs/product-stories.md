# 產品主線與 User Story

Bus coming soon 支援從問題辨識到路線方案比較的工作流程：**探索現況 → 改善清單 → 路線編輯 → 影響比較 → 共同討論**。市府與業者提出調整方案，居民與地方團體檢視服務影響，工會及駕駛代表檢視工作條件。

「已實作」依目前 `web/` 程式與操作文件；「設計完成」指 Penpot 畫面與規格已存在，尚待程式與資料接入。設計數字、原型連結及操作意圖不等於實際分析或執行驗證。沿用原有 US-01 至 US-07，新增 US-08 改善清單、US-09 路線編輯，以下依使用流程排列。

## 核心故事與完成條件

| US-07 共同討論 | 作為居民或地方團體，我想分享相同的分析視圖並查閱資料來源，讓討論有共同依據。 | 分享能還原地圖與分析設定；區分觀測、計畫、推估、示意與缺值；方案與清單輸出保留比較條件及資料限制。 | 地圖／清單分享、CSV 匯出及方法說明已實作；路線方案分享待開發。 |

US-08 的實作完成條件：

- 地圖與清單共用時段、篩選與門檻；變更後更新分數、標籤及排名，表頭指出排序欄位與方向。
- 點列展開詳情，關閉後保留清單；「在地圖上檢視」帶入選取路線與時段；「加入路線編輯方案」銜接 US-09。
- 優先分數呈現捷運重疊、路線堆疊、低載程度與冷區比例的構成與權重，區分幾何、站點與旅次重疊。設計權重與門檻仍待分析驗證。
- 空結果提供調整門檻或重設入口，重算中顯示狀態；MOCK 在導覽、欄位、KPI 與詳情保留標示，CSV 匯出目前篩選結果並保留 `is_mock` 資訊。

DRTS 區塊與端點站分類、表格及詳情已實作；區塊需求、勤務與休息仍以 Mock Data 呈現。完整 DRTS 與駕駛休息分析分別參照[第 05 頁](https://penpot.c3land.org/#/workspace?file-id=94a073f9-47a7-80c1-8008-d636bc5359e3&page-id=eb5b2b24-f2e1-80de-8008-d64a336cb9b3)與[第 06 頁](https://penpot.c3land.org/#/workspace?file-id=94a073f9-47a7-80c1-8008-d636bc5359e3&page-id=c5a7fe42-22aa-802c-8008-d65e61f9aa04)。

設計稿中的優先分數、數量與處置建議應按示意閱讀。旅次重疊、載客、冷區與可重新配置車輛時含 MOCK；即使畫面標註真實來源，也須核對來源期間、計算與連接方式後才能作為分析結果。共站或線形平行不能直接推論乘客重複，缺運量也不能以戶籍人口或計畫班次替代。

清單可帶著附線／方向與日期時段進入編輯草稿，不自動套用建議。操作與真實／模擬資料的計算範圍見[改善清單說明](improvement-list.md)。

## 路線工具（第 04-01 頁）

[設計入口](https://penpot.c3land.org/#/workspace?file-id=94a073f9-47a7-80c1-8008-d636bc5359e3&page-id=7a48f695-9549-80a2-8008-d66746020a41&board-id=7a48f695-9549-80a2-8008-d66897f2a5f7)對應 US-09 的編輯與 US-04 的影響比較：

1. 從頂列「路線工具」新增路線，或搜尋主路線後選擇附線與方向。
2. 調整停靠站、站序、路徑控制點與所選時段班次。
3. 預覽相對原始現況的累積人口、設施與班次變化；刪除主路線時一併評估所有附線方向與替代服務。
4. 完成試算後套用到本機方案，可再次檢視影響或逐次復原最近 20 次套用。

可達人口以同一網格去重；高齡與學生顯示未估算。單程時間是草圖估時，路徑沒有自動沿路導航。完整操作、保存行為、班表與人口假設見[路線方案工具](route-editor.md)。
