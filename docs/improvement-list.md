# 改善優先清單

依 [Penpot 第 07 頁](https://penpot.c3land.org/#/workspace?file-id=94a073f9-47a7-80c1-8008-d636bc5359e3&page-id=cd01f655-524b-80aa-8008-d66db7246b95&board-id=cd01f655-524b-80aa-8008-d66f03883703)實作，入口為頂列「改善清單」，沿用 React、TypeScript、MapLibre；目前聚焦桌面。

## 操作

- 路線、站位／路段、DRTS 區塊、端點站共用日期、時段、行政區、問題、門檻與搜尋。問題採任一符合；不同篩選條件需同時符合。
- 表頭切換排序，每頁 10 筆；低於 60 分預設收合，可在表格下方展開。偏好可調整四項權重，依總和換算至 100 分。
- 點列開啟 520 px 詳情側欄，再點同列、關閉或 Escape 收合。側欄提供分數拆解、真實供給與 Mock 載客／休息圖表、建議影響。
- 地圖與清單使用同一組篩選與選取。分享連結保留分類、條件、排序、權重與選取；不包含路線工具的本機方案。
- CSV 匯出目前篩選下的全部頁面，保留來源時間、條件、真實與模擬欄位的 `is_mock` 標記；缺值留空。若要匯出低優先項目，先勾選顯示。
- 「加入路線編輯方案」以原生附線／方向 ID 開啟編輯草稿，帶入日期與時段，不自動套用建議。非路線詳情可先選關聯主路線。已被本機方案刪除的路線須先復原。

空結果會分別提示關鍵字沒有命中、行政區／問題條件排除結果，或符合條件的項目全部低於 60 分。關鍵字不存在時可「清除搜尋」，不會建議放寬評分門檻；只有低優先項目被收合時才提供「顯示低優先項目」。清除搜尋保留其他篩選，「重設為預設值」則還原目前分類的預設條件並保留清單／地圖視角。篩選完成且無結果時，以即時狀態區提供原因，供螢幕閱讀器播報；輸入搜尋時不移動焦點。

## 真實資料與 Mock Data

| 資料 | 使用方式與限制 |
| --- | --- |
| 公運處路線、站序、站位、班表 | 主路線、實體站位與附線以原生 ID 關聯。共站數按主路線去重；班次按附線去重、不因方向重複相加。平日採週三代表，依起站發車小時計入。全日 00–24，尖峰 07–09／17–19，離峰 09–17。缺班表標記 `†`，完全缺少保留 `null`。 |
| 幾何重疊 | 可用精確附線／方向線形聯集在 OSM 捷運線 100 m 緩衝內的長度比例；不以站序直線補算缺線形。詳情揭露有線形方向數。 |
| 站點重疊與最近捷運 | 不重複實體站位距 OSM 站心 300 m 內的比例，距離以 EPSG:3826 計算；非出入口或步行路網。 |
| DRTS 地理區塊 | 1 km TM2 方格，包含臺北市實際站位；人口由既有 100 m 面積分攤資料按格心彙整，來源為 2024-12 人口與 2015 統計區界。不是 H3/Gi* 的實測冷點；缺人口格另列。 |
| 端點與公廁 | 端點為附線方向的首末站，不等同調度場站。最近公廁僅使用臺北市官方資料；位置不保證開放、停車或駕駛可進入。 |
| Mock Data | 旅次重疊、每班次載客、載客剖面、冷區比例、勤務休息、建議影響採固定種子示意模型。分數、問題標籤與建議混合真實供給及模擬需求，均揭露 Mock；不是票證 OD、年度運量拆分或實測工作時數。 |

優先分數與標籤公式可從清單下方「指標與來源」查閱。所有來源 URL、版本、排除項目與方法記在輸出 `metadata`，資料範圍是臺北市主管機關 feed，保留跨市服務但不含全部新北市路線。清單的來源網路不會隨本機編輯方案變動；實際方案影響另由路線工具試算。

## 產生與驗證

啟動開發伺服器後，開啟 `/tests/mapRecovery.browser.html?app=1` 並進入「改善清單」。按「保存清單狀態區」，搜尋到只剩一列後輸入不存在的關鍵字，再按「檢查清單狀態區」；同一狀態區須包含空結果標題。變更空結果原因、清除搜尋後重做檢查，狀態區仍保留、有結果時清空；輸入搜尋時焦點不移動。此檢查涵蓋 DOM／ARIA 更新，不代表已完成各螢幕閱讀器實測。

```bash
# 重建所有前端圖層，包含路線工具及改善清單
uv run scripts/build_web_data.py
# 前置圖層已更新時，只重建改善清單
uv run scripts/build_improvements.py
npm --prefix web run test:improvements
npm --prefix web run test:routes
npm --prefix web run build
```

產生器只擁有 `web/public/data/improvements.json`，衍生檔不進 Git。GitHub Pages 工作流程會重建資料並執行必要檢查。[獨立資料巡檢](../data/quality/web_improvements_review.json)涵蓋來源、ID、班表、空間計算、人口與缺值。
