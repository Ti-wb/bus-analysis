# 路線方案工具

依 [Penpot 04-01](https://penpot.c3land.org/#/workspace?file-id=94a073f9-47a7-80c1-8008-d636bc5359e3&page-id=7a48f695-9549-80a2-8008-d66746020a41&board-id=7a48f695-9549-80a2-8008-d66897f2a5f7) 實作，入口在頂列「路線工具」。沿用 React、TypeScript、MapLibre 與本機資料，不需要後端。

## 操作

- 新增：命名路線，從地圖、全域搜尋或站序搜尋加入現有公車站；至少兩個不同停靠站才可預覽。
- 編輯：搜尋主路線，選擇附線與方向。拖曳清單或用上下按鈕調整站序；可新增、取消停靠及調整選定時段班次。其餘附線方向維持原狀。
- 路徑：可加入及拖曳控制點，也可用方向鍵微調、Delete 移除。站序更動會重建站間連線。草圖不會自動沿道路導航，也未檢查單行、禁轉或車輛可行性。
- 預覽：比較與原始現況的累積變化；返回保留站序、方向、班次與時段。完成計算後才可套用；計算失敗可重試，離開未套用草稿會提示保留或放棄。
- 刪除：移除整條主路線的所有附線方向，先看替代服務再確認。刪除後單程時間不適用。
- 套用：只寫入此瀏覽器的 localStorage；不改動資料來源或實際營運。「再次檢視影響」是唯讀回顧，關閉保留方案。可逐次復原最近 20 次套用，回顧沿用套用時的時段與估時假設。

重新載入會還原已套用方案；草稿不跨重新載入保存。來源站序時間改變、版本或內容無法驗證時，不載入舊方案並顯示提示。方案沒有上傳或分享功能；分享視圖支援探索地圖及改善清單的分析條件。

## 計算邊界

- 固定使用臺北市約 100 m 網格、公車／捷運 350 m 直線可達；所有人口比較使用同一份原始路網與同一時段。YouBike 1 km 另列，不加入步行可達人口。
- 公車來自臺北市公運處 feed，不是完整雙北路網。附線／方向按來源 ID 精確連接站序；缺主檔、少於兩站等排除記在輸出 metadata。原線形只用精確 ID／方向匹配，否則以站序連線。
- **班表未分方向**：假設同一附線班表可用於各方向，畫面持續揭露。平日以週三代表；每小時固定班表優先，其餘由兩個班距欄位的平均值換算，依起站發車時刻，未加到站旅時。同一附線方向在同格只算一次，其他附線分開算。
- 早峰 07–09、離峰 09–17、晚峰 17–19、晚間 19–23，保留既有週六／日 07–23；另支援改善清單傳入的各日全日 00–24 及週末分時段，均為 Asia/Taipei。修改班次只作用於所選時段情境，不自動換算到其他重疊時段；新線其他時段未設定時維持未知。
- 人口是 2024-12 戶籍人口、2015 最小統計區界。先把每區人口按面積分攤到互斥網格，再按格心可達去重；不是相鄰站點人口相加。市界裁切使用目前前端的簡化臺北市界。有資料面積低於或等於 0.5% 的格子維持 null，不視為零人口。
- 有已知班次或捷運可達的居民為可確認人口，只有缺班表路線的格子另納入可能上限。新增／失去服務只有能確認的部分才計入；不確定變化另外列出。仍可達但班次下降的人口與失去可達人口分開。
- 高齡及就學身分未接入，顯示「未估算」，不使用設計示意數字或年齡代理學生。戶籍人口不是運量、白天活動人口或營運收益。
- 重要設施沿用預設的學校、醫院、商場市場、社宅、市政司法候選，取調整路線站點 1 km 內。距離為最近仍有可能服務的公車／捷運站；公車班次只算 350 m 內並按附線方向去重，缺班表顯示下限；捷運無班次資料。設施候選並未去重或驗證出入口。
- 單程時間採圖上線長 ÷ 假設速度，加每站停靠秒數；預設 18 km/h、30 秒，可在路線偏好調整。這是可編輯草圖的估時，不是已接入 TDX 站間旅時或路況的模型。

## 產生與驗證

```bash
# 同時產生既有圖層及 route_scenario.json
uv run scripts/build_web_data.py
# 圖層已更新時，只重建路線工具資料
uv run scripts/build_route_scenario.py
npm --prefix web run test:routes
npm --prefix web run build
```

產生器只擁有 `web/public/data/route_scenario.json`，衍生檔不進 Git；保留來源 URL、版本、期間、計算與缺漏定義。前端 `web/src/routeEditor/` 將試算放在可取消的 Worker，過期結果不能覆蓋新草稿。必要回歸使用既有 Vite TypeScript 管線與 Node 原生測試，不另加測試套件。

[獨立資料巡檢](../data/quality/web_route_scenario_review.json)涵蓋來源、附線／站序、班表、網格人口、站點半徑與加總。靜態試算不代表實際路線調整成效或營運可行性。
